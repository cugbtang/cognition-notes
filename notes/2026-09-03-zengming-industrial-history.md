# 和曾鸣聊产业史观：残酷的真相、会消亡的公司

> 用商业史的长镜头看，2026 年约等于「1992 年建站运动刚兴起、浏览器还没诞生」；大模型只是刚完成基础设施化，真正的大机会在尚未出现的 Agent 入口，而「公司」这种组织形态本身也会被改写。

## 核心框架：技术产业化三阶段

曾鸣把通用颠覆性技术的产业化拆成三段，并给出一条「断代律」。

| 阶段 | 产业任务 | 竞争要素 | 历史对照 | AI 对应 | 时间坐标 |
| --- | --- | --- | --- | --- | --- |
| 1 基础设施化 | 技术被社会接受、成为可计价的基础设施 | 原创技术、可不可用 | 电网 / AOL 接入 | 大模型 · token 计价 | 2026 基本收官 |
| 2 应用大爆发 | 基于低成本基础设施，海量应用百花齐放 | 产品洞察、用户同理心 | 浏览器 / Yahoo 目录 | Agent · 分享能力 | 3~5 年的窗口 |
| 3 原生应用阶段 | 需要更底层的方法运行新世界，新物种确立 | 新范式定义权 | Google / 抖音·拼多多 | Agent OS · 意图调度 | 约 8~10 年后 |

**断代律**：「我能看到的理论框架告诉我：第一阶段的企业，很难活到第二阶段；第二阶段的企业，很难活到第三阶段。」原因是第二阶段的技术核心变了（从技术原创性变成产品原创力），而应用的爆发又反过来为下一阶段指明方向 —— 所以第二阶段绕不过去。

**2026 的坐标**：基础设施建设完成的标志是形成了标准度量衡。黄仁勋称英伟达的未来是 token factory，Sam Altman 称 OpenAI 的核心是卖 token —— 当「多少 token 能干多少活、产生多少费用」成为共识，智能就像一度电、一吨水一样成了社会基础设施。同时 OpenClaw 一类能独立完成任务的 Agent 让大家看到应用阶段的开场。但曾鸣今年把判断**前移**了：「产业化还没有到浏览器阶段。不是浏览器出来以后发生了什么，而是浏览器本身都还没出现。」

## 关键判断

1. **从信息时代进入能力时代。** 1992 年建站是分享信息，今天做 Agent / skill 是「把自己懂的能力封装起来，分享出去让别人调用」。浏览器当年干了两件事：用 HTML 统一建站标准（供给端爆发）、把浏览门槛降到零（用户端爆发），网站多到看不过来才有 Yahoo 做目录做熵减。今天 skill 在熵增式爆发，但「我完全没看到 Yahoo 的雏形」。

2. **模型公司 = 未来的 AI 云公司，大概率不是原生时代大赢家。** 数据是石油、模型是炼油厂；从接入角度看大模型更像 AOL —— 让所有人接入智能的入口。「石油公司肯定做不了汽车，你没听说过哪家汽车公司是由石油公司转化来的。」模型公司与云厂商的博弈最终会整合成几家 AI 云公司。

3. **基础设施只有一种成立的商业模式：寡头垄断 + 政府强监管。** 社会依赖所以强监管，供给重要所以不能只有一家，投入巨大所以不会无序竞争。「你现在水电费能随便涨价吗？」寡头竞争的特征是「有一定差异化，但又足够同质化」—— 同质化保证可替代，差异化让大家还有钱赚。结论是「很好的**成熟**生意」：只要有同质化供给，就不可能获取高额利润。

4. **万亿估值不是史无前例，是「这次不一样」的幻觉。** Yahoo 1995 年成立、2000 年市值 1200 亿美元（按通胀与纳指涨幅折今天约 1 万亿）；AOL 2000 年高点 2200 亿、并购时代华纳后 3000 多亿；Google 1998 年成立、2005 年破千亿。第一波跑出来的公司历来就有这么大价值，「但不一定能活到最后」。曾鸣相信未来会有 10 万亿美元的公司，「但未必是现在领跑的这两家」。

5. **最大空白是 Agent 时代的浏览器 / Netscape / Yahoo。** 谁统一 Agent 标准、让用户极简调用、并解决「你敢把钱包和隐私交给 Agent 吗」的信任问题，谁就是入口（未来 3~5 年可能出现）。新平台不来自旧平台：旧平台做简单信息匹配，新平台做「能力 × 需求」匹配，复杂度不是一个量级。Agentic OS 属于第三阶段，现在谈落地为时过早。

6. **「公司」会消亡，组织基本单元从岗位变成任务。** 公司是工业时代的配套制度：岗位 → 汇报线 → 层级 → 报酬。AI 原生组织围绕任务流转，硅基与碳基员工协同，「谁的能力强，谁被调用」；层级与中层消失，贡献透明、靠自驱，越来越像合伙人企业或球队（大 lab 已是「任务发布、能干就接、交付就上线」）。neo lab 是新组织形态的雏形，第一个其实是 OpenAI。「一人公司」只是阶段性产物 —— 每个人都是六边形战士，再彼此协作。

7. **优秀 ≠ 卓越；战略从「规划」变成「生成」。** 优秀是持续正反馈，卓越是事后认定、来自穿越一轮轮负反馈的反共识（但反共识不一定成功，有幸存者偏差）。公司四级：机会驱动 → 战略驱动 → 远见驱动 → **使命驱动**。方法上「看十年、想三年、干一年」，真正的创造力在「想三年」；ARR 逐月增长是线性外推幻觉；组织先于战略，靠 Context not Control 让洞察涌现 ——「实际上是人跟 AI 一起在训练一个组织的小模型」。

8. **巨浪面前没有人是安全的。** 移动互联网对 PC 互联网是「1.5 倍创新」（延续性让头部顺利过渡），而 **AI 是生产力革命、互联网是生产关系革命**，延续性弱，跨代际还能做好的企业「不是多不多的问题，是有没有的问题 —— 基本没有」（IBM、微软各算一次）。他的态度反而豁达：「人有生老病死，公司也有生老病死……这样，新公司才有机会，年轻人才有梦想。」

## 可落地推论

- **应用创业别做简单任务**：「当智能能力不够时，做应用很大程度上是在搭脚手架，等着模型能力自然提升，把脚手架淹没」。要找 10 倍以上的复杂切入点；他看好增长、教育、健康、To B「组织大脑 / CEO Agent 团队」。
- **不用自训模型**：模型能力会变成可稳定调用的大宗商品，重点是「有合理的替代品随时能接上」。Cursor 类产品在模型能力不够时试探边界，模型一发展就被 fold into 迭代。
- **不要用 ARR 做线性外推**：只问一句「继续涨两年以后又怎么样？天花板多快会来？」竞争一多，定价从客户价值变成边际成本。
- **组织改造不能靠给现有工具加 AI 插件**：原 ERP 是「固化的道路」，不可能是实时反应的网络；一号位要亲自重写公司内部运行体系。
- **心态**：从降低不确定性转向拥抱不确定性；曾鸣认为当下最关键的 bet 是「出现一个足够好用的 To C Agent」，并把工作室名「语言即世界」改成了「智能体即世界」。

## 存疑 / 待验证

- [ ] 「OpenAI、Anthropic 大概率不是原生应用阶段大赢家」—— 验证时间 2032 前后；看是否出现不在二者之内的入口级公司。
- [ ] 「2026 年底跑不到 3T 参数的公司出局」—— 验证时间 2026-12；口径本身模糊（参数量 ≠ 能力），需先定义什么叫「出局」。
- [ ] 「3~5 年出现 Agent 入口、8~10 年出现原生应用」—— 验证时间 2029 / 2034。
- [ ] 「xAI、Meta 已退出竞赛」—— 强主观判断，且随组织与模型迭代可能快速反转。
- [ ] 论证跳跃：从「历史上第一阶段企业难活到第二阶段」直接推到「当前模型公司不是大赢家」，属于类比归纳，样本主要来自 PC / 移动互联网，AI 的基础设施属性（可自我改进、智能复利）可能改变迁移规律。
- [ ] 全篇是产业史框架的推演，非事实结论；曾鸣本人强调「不做短期预测，只提供规律性的理解」。

## 延伸问题

- 如果模型能力持续自我改进（智能复利），「基础设施」与「应用」的边界会不会根本不出现？这才是「这次真不一样」的最强论据。
- 三阶段模型解释不了什么？例如开源模型与本地推理让基础设施无法形成寡头定价权时，第 3 条判断的前提是否还成立。
- 若「公司消亡」成立，责任、合规、税务与知识产权这些制度配套如何迁移到任务型组织？访谈未展开。
